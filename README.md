# ⚡ 브레드보드 회로 시뮬레이터

웹 브라우저에서 전자회로를 직접 꾸미고 작동시켜 볼 수 있는 브레드보드 실습 프로그램입니다.
LED, 저항, 스위치, 전원을 브레드보드에 꽂고 전선으로 연결하면 실제 회로처럼 LED가 켜지고,
수정 절점 해석(MNA)으로 계산한 전압·전류가 실시간으로 표시됩니다.

## 바로 실행하기

### 방법 1 — 파일 더블클릭 (설치 필요 없음)

저장소를 내려받은 뒤 `breadboard-simulator.html` 파일을 더블클릭하면 브라우저에서 바로 열립니다.
인터넷 연결 없이도 작동합니다.

### 방법 2 — 개발 서버

[Node.js](https://nodejs.org) 18 이상이 필요합니다.

```bash
npm install
npm run dev        # http://localhost:5173 에서 열림
```

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 (코드 수정 시 자동 새로고침) |
| `npm run build` | `dist/index.html` 한 파일로 빌드 (JS·CSS 포함) |
| `npm run preview` | 빌드 결과를 로컬 서버로 확인 |
| `npm test` | 회로 계산 단위 테스트 |

코드를 수정한 뒤 더블클릭용 파일을 갱신하려면:

```bash
npm run build
cp dist/index.html breadboard-simulator.html
```

| --- | --- |

| 부품 | LED(빨강·초록·파랑·노랑), 저항(색띠 자동 표시), 푸시 버튼, 슬라이드 스위치, 9V 배터리, DC 전원 공급 장치 |
| 부품 배치 | 도구 상자에서 끌어다 놓기 또는 클릭으로 추가, 드래그로 이동, 90° 회전 |
| 전선 연결 | 구멍에서 구멍으로 드래그(또는 클릭-클릭), 직각으로 꺾이는 배선, 꺾이는 점 추가·이동·삭제, 8가지 색상, 끝점 옮기기 |
| 편집 | 되돌리기 / 다시하기 (Ctrl+Z / Ctrl+Y, 최근 100단계), 부품 이름표 표시·이름 변경 |
| 회로 작동 | 회로가 완성되면 LED 점등(전류에 따라 밝기 변화), 연결을 바꾸면 즉시 갱신 |
| 전기 계산 | 부품별 전압·전류·전력, 구멍별 전압, 전원 공급 장치 화면에 V/A와 CV/CC 모드 표시 |
| 회로 진단 | 단락(쇼트), LED 과전류·소손, 극성 반대, 저항 과열, 미연결 단자·끝이 빈 전선 경고 |
| 저장 | 작업 내용이 브라우저에 자동 저장되어 새로고침해도 유지 |
| 예제 | 버튼으로 켜는 빨간 LED + 스위치로 켜는 초록 LED 회로 |

## 사용 방법

- **부품 추가**: 왼쪽 도구 상자에서 부품을 작업 영역으로 끌어다 놓거나 클릭합니다.
- **부품 이동**: 부품 몸체를 드래그합니다. 다리는 가까운 구멍에 자동으로 맞춰집니다.
- **전선 연결**: 구멍(또는 부품 단자)에서 다른 구멍까지 드래그합니다. 전선은 가로·세로로만 직각으로 꺾여 그려집니다.
- **꺾이는 점 넣으며 그리기**: 시작 구멍을 한 번 클릭하고, 빈 곳을 클릭할 때마다 꺾이는 점이 생기며, 끝 구멍을 클릭하면 완성됩니다.
- **전선 수정**: 전선을 클릭해 선택한 뒤
  - 흰색 끝점을 끌어 다른 구멍으로 옮기고,
  - 전선을 더블클릭하면 그 자리에 꺾이는 점(사각형)이 추가되며,
  - 사각형을 끌어 경로를 바꾸고, 사각형을 더블클릭하면 지웁니다.
  - 색상은 상단 색상 버튼으로 바꿉니다.
- **이름표**: 부품 위에 이름표가 표시됩니다. 오른쪽 패널에서 이름을 바꿀 수 있고, 상단 🏷 이름표 버튼으로 숨길 수 있습니다.
- **푸시 버튼**: 빨간 버튼을 누르고 있는 동안만 연결됩니다.
- **스위치**: 레버를 클릭해 ON/OFF를 바꿉니다.
- **속성 변경**: 부품을 선택하면 오른쪽 패널에서 저항값, LED 색, 전원 전압, 전원 장치의 전류 제한을 바꿀 수 있습니다.
- **연결 확인**: 구멍에 마우스를 올리면 함께 연결된 구멍이 파란색으로 표시되고, 아래 상태 표시줄에 그 지점의 전압이 나옵니다.

| 단축키 | 동작 |
| --- | --- |
| `R` | 선택한 부품 회전 |
| `Delete` / `Backspace` | 선택한 부품·전선 삭제 |
| `Esc` | 선택 해제 / 전선 그리기 취소 |
| `Ctrl`+`Z` | 되돌리기 |
| `Ctrl`+`Y` / `Ctrl`+`Shift`+`Z` | 다시하기 |

상단의 **▶ 실행 / ■ 정지**로 시뮬레이션을 켜고 끄며, **초기화**는 회로 전체를 지웁니다.

## 회로 계산 방식

회로는 **수정 절점 해석(MNA)** 으로 계산합니다. 브레드보드의 내부 연결과 전선으로 이어진 구멍들을 하나의 절점으로 묶은 뒤,
각 부품을 아래 모델로 바꿔 연립방정식을 풉니다.

| 부품 | 모델 |
| --- | --- |
| 저항 | 옴의 법칙 V = I × R, 소비 전력 1/4W 초과 시 경고 |
| LED | 순방향 전압 Vf(빨강 1.8V, 초록 2.1V, 파랑 3.0V, 노랑 2.0V) + 직렬저항 15Ω. Vf보다 높은 전압이 걸릴 때만 켜짐 |
| 9V 배터리 | 내부저항 1.5Ω의 전압원 |
| DC 전원 공급 장치 | 내부저항 0.1Ω. 평소에는 정전압(CV), 출력 전류가 설정한 제한값을 넘으면 정전류(CC)로 바뀌어 전류를 제한값에 고정 |
| 스위치·버튼 | 닫히면 1mΩ, 열리면 끊어짐 |

LED 켜짐/꺼짐과 전원 장치의 CV/CC는 상태에 따라 회로가 달라지므로, 모든 상태가 서로 모순되지 않을 때까지 반복해서 다시 풉니다.
한 번에 하나(조건을 가장 크게 어긴 LED)만 바꾸므로 여러 LED가 병렬로 있어도 상태가 진동하지 않습니다.

스위치가 열려 전원과 끊긴 부분은 GND 기준 0V 근처의 유한한 값으로 계산되고, '전원과 이어지지 않음'으로 표시됩니다.

판정 기준:

- **단락**: 전원 +와 − 사이의 외부 저항(단자 전압 ÷ 출력 전류)이 0.5Ω 미만. CC 모드로 보호되는 경우는 경고로 낮춤
- **저항 과열**: 소비 전력 0.25W 초과 시 경고, 1W 초과 시 오류 (예: 9V에 5Ω → 약 1.38A, 9.6W → 단락이 아니라 저항 과열)
- **LED**: 20mA에서 최대 밝기, 30mA 초과 시 과전류 경고, 100mA 초과 시 소손
- **미연결**: 다른 무엇과도 닿지 않은 부품 단자, 한쪽 끝이 빈 줄에 꽂힌 전선

예) 9V 배터리 + 470Ω + 빨간 LED → I = (9 − 1.8) / (470 + 15 + 1.5) ≈ 14.8mA

> 교육용 단순화 모델입니다. LED는 실제 다이오드 곡선 대신 문턱 전압 + 저항으로 근사하며, 직류(DC) 회로만 다룹니다.

## 프로젝트 구조

```
BREADBOARD/
├─ breadboard-simulator.html  더블클릭으로 바로 실행 (빌드 결과물)
├─ index.html
├─ vite.config.js            Vite 설정 (한 파일 빌드)
├─ tests/
│  └─ simulate.test.js       회로 계산·되돌리기 테스트
└─ src/
   ├─ main.jsx               진입점
   ├─ App.jsx                전체 상태, 키보드 단축키, 버튼 눌림 처리
   ├─ styles.css             다크 테마, 반응형 레이아웃
   ├─ components/
   │  ├─ Toolbar.jsx         실행/정지/초기화/예제, 되돌리기/다시하기, 회전/삭제, 이름표, 전선 색
   │  ├─ Toolbox.jsx         부품 도구 상자
   │  ├─ Workspace.jsx       작업 영역: 부품 이동, 직각 전선·꺾이는 점, 이름표, 선택
   │  ├─ Breadboard.jsx      브레드보드 그림
   │  ├─ PartView.jsx        부품별 그림
   │  └─ PropertiesPanel.jsx 속성 편집, 전압·전류, 회로 진단
   └─ lib/
      ├─ board.js            구멍 좌표와 내부 연결 구조
      ├─ parts.js            부품 정의 (핀 위치, 기본값, 회전)
      ├─ simulate.js         회로 해석과 경고
      ├─ state.js            상태 변경, 되돌리기 기록, 자동 저장, 예제 회로
      └─ format.js           단위 표기, 저항 색띠
```

## 기술 스택

React 18 · Vite 6 · SVG · JavaScript (외부 회로 라이브러리 없이 직접 구현)

## 알려진 제한

- 푸시 버튼은 실제 4핀 대신 2핀으로 단순화했습니다.
- 화면 확대/축소는 아직 지원하지 않습니다.
- 좁은 화면에서는 작업 영역을 가로로 스크롤해야 합니다.
